# HỆ THỐNG BÁN HÀNG BÁNH MÌ MẸ TÔM TÉP

Sản phẩm cá nhân tham gia cuộc thi Vibe Coding (Phase 2).

## 1. Môn học / Dự án
- Tên dự án: Bánh mì Mẹ Tôm Tép
- Quy mô: Hệ thống quản lý và đặt hàng bánh mì cho quán nhỏ (20-30 đơn/ngày).

## 2. Các chức năng chính
- Chức năng 1: Quản lý Menu / Món ăn (Thêm, sửa, cập nhật trạng thái món).
- Chức năng 2: Đặt hàng & Quản lý đơn hàng (Tạo giỏ hàng, đặt đơn, chuyển trạng thái đơn).
- Chức năng 3: Quản lý khách hàng & Báo cáo doanh thu cơ bản.

## 3. Công nghệ sử dụng
- Frontend & Backend: Next.js / HTML, CSS, JavaScript.
- Cơ sở dữ liệu: SQLite / PostgreSQL.
